# Skills used on this project

Which installed skills to use, and when. Grouped by the work they serve.

## Every build or design session

| Skill                 | Why                                                 |
| --------------------- | --------------------------------------------------- |
| `karpathy-guidelines` | Small, surgical changes with clear success checks   |
| `ui-ux-pro-max`       | Baseline UI and UX standards before any design work |

## Visual identity (before Phase 1 builds the editor chrome)

| Skill                                                                                                                              | Why                                                                                                                                                                         |
| ---------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `taste-from-the-real-web`, `design-taste-frontend`                                                                                 | Ground directions in real, well-made references                                                                                                                             |
| `awwwards`                                                                                                                         | Its art-direction process and craft bar. It targets marketing sites and defaults to Next.js, so we use its method, not its stack. Fully applicable to a future landing page |
| `emil-design-eng`, `audit-ai-design-slop`, `uxkin:no-ui-slop`, `vectorlab-ux-skills:anti-slop`                                     | Keep the editor away from the generic AI look                                                                                                                               |
| `color-system`, `dark-mode-design`, `typography-scale`, `critique-typography`, `spacing-system`, `layout-grid`, `visual-hierarchy` | Build the editor's own token set                                                                                                                                            |
| Mobbin search                                                                                                                      | Real references, linked for review, never saved to the account                                                                                                              |
| `docs/DESIGN.md`                                                                                                                   | The lock for our custom identity. `design-drift` only locks its bundled brands, so it does not apply here                                                                   |

## Gates (end of each UI sub-milestone and each phase)

| Skill                                       | When                                                                                                              |
| ------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| `principles-and-laws-audit`                 | Every UI sub-milestone: principles, UX laws, NN/g heuristics, craft and polish, ranked fixes                      |
| `jury`                                      | Phase gates, on a running build or Vercel preview: measured LCP, CLS, axe, keyboard focus, plus a scored critique |
| `heuristic-evaluation`, `ux-laws-checklist` | Deeper review when the audit flags a flow                                                                         |
